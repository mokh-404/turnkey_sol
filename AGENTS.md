# Turnkey Show Alamein - Project Guidelines

## Site structure

- Keep the public experience in file-based TanStack routes, with shared navigation and page framing in `src/components/SiteLayout.tsx`, so every page retains consistent navigation and metadata remains route-specific.
- Styling is defined according to the official "TURN KEY Guideline 2026" in `src/site.css` with League Spartan typography, 55% Black / 30% White / 15% Red palette, and architectural layout rules.
