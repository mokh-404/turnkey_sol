# Arabic Voice & Glossary — Turnkey Show Website

Source of truth: `Brochure Turnkey Show Arabic 2027_compressed.pdf` (the official Arabic brochure).
Every Arabic string on the site must sound like that brochure: confident, editorial, Modern Standard
Arabic with a business tone. Short declarative headlines, no filler, no web clichés.

## Hard rules

1. **No generic web filler.** Never write: «انقر هنا»، «اضغط هنا»، «اقرأ المزيد»، «مرحباً بكم في موقعنا»،
   «لا تتردد في التواصل»، «نحن هنا لمساعدتك»، «اكتشف الآن». Buttons state the action plainly:
   «احجز مساحتك»، «سجّل زيارتك»، «حمّل البروشور»، «تواصل معنا»، «أرسل الطلب».
2. **Not a word-for-word translation.** Rewrite the English idea the way the brochure would say it.
   Prefer the brochure's exact phrasing wherever the same idea exists (see the phrase bank below).
3. **Brand name**: «معرض العلمين تيرن كي شو» (full) · «معرض تيرن كي» / «تيرن كي شو» (short).
   Keep Latin «Turnkey Show» only inside logos / alt text of the logo.
4. **Numbers**: big stats & dates use Arabic-Indic digits like the brochure (٢٠٢٧، ١٫٢، ٤٦٬١٨٩+).
   Phone numbers, emails, URLs, form values and prices in code stay Western/Latin.
   `AnimatedCounter` converts digits automatically on `/ar` pages — pass Western digits to it.
5. **Never letter-space or uppercase Arabic** — CSS handles this; do not add `letter-spacing` inline.
6. **Form option `value`s stay in English** (the backend & emails depend on them). Only the visible
   label is translated.
7. Use «ـ» elongation (كشيدة) **never** in running text.
